# nimaapp.pro

Landing page for Nima. A single static `index.html`, hosted free on GitHub Pages.

- `index.html` — the page (all CSS inline; fonts from Google Fonts)
- `assets/` — wordmark, favicon, touch icon, social preview image, grain texture
- `CNAME` — tells GitHub Pages to serve this repo at `nimaapp.pro`

Edit `index.html` and push to `main`; GitHub Pages redeploys in about a minute.

⚠ The custom domain belongs to THIS repo only. Do not set it on `nima-privacy` or
create an `aldahir10m.github.io` user site with it: that would move the privacy
policy and password-reset URLs the App Store listing and Supabase emails depend on.
